## Instruções para o Claude Code

Use este arquivo como fonte do catálogo. Atualize os registros pelo ID do YouTube e despublique os vídeos retirados das versões antigas. Preserve a numeração original e as lacunas. Se uma linha tiver um intervalo marcado como vídeo único, mostre esse intervalo como uma única opção no player. Use o iframe oficial do YouTube e mantenha a reprodução pública.

Antes de publicar, teste os vídeos no domínio final a partir do Brasil e confira a faixa PT-BR. Em caso de erro no player, mostre “Episódio indisponível no momento” e ofereça outro episódio disponível. Para validar novos títulos, consulte contentDetails.regionRestriction e status.embeddable na API do YouTube.
